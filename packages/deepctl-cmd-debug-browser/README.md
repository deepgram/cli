# deepctl-cmd-debug-browser

> Part of [deepctl](https://github.com/deepgram/cli) — Official Deepgram CLI

Browser debug subcommand for deepctl

This is a subcommand of `deepctl debug`.

## Installation

Installed automatically with deepctl:

```bash
pip install deepctl
```

## Commands

| Command | Entry Point |
|---------|-------------|
| `deepctl debug browser` | `deepctl_cmd_debug_browser.command:BrowserCommand` |

## Dependencies

- `click>=8.0.0`
- `rich>=13.0.0`
- `pydantic>=2.0.0`
- `httpx>=0.24.0`
- `aiohttp>=3.9.0`
