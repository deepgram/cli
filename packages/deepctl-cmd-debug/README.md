# deepctl-cmd-debug

> Part of [deepctl](https://github.com/deepgram/cli) — Official Deepgram CLI

Debug command group for deepctl

## Installation

Installed automatically with deepctl:

```bash
pip install deepctl
```

## Commands

| Command | Entry Point |
|---------|-------------|
| `deepctl debug` | `deepctl_cmd_debug.command:DebugCommand` |

## Dependencies

- `click>=8.0.0`
- `rich>=13.0.0`
- `pydantic>=2.0.0`
