# deepctl-cmd-init

> Part of [deepctl](https://github.com/deepgram/cli) — Official Deepgram CLI

Init command for deepctl — scaffold Deepgram starter apps

## Installation

Installed automatically with deepctl:

```bash
pip install deepctl
```

## Commands

| Command | Entry Point |
|---------|-------------|
| `deepctl init` | `deepctl_cmd_init.command:InitCommand` |

## Dependencies

- `click>=8.0.0`
- `rich>=13.0.0`
- `httpx>=0.24.0`
- `pydantic>=2.0.0`
