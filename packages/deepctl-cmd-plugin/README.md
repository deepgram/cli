# deepctl-cmd-plugin

> Part of [deepctl](https://github.com/deepgram/cli) — Official Deepgram CLI

Plugin management command for deepctl

## Installation

Installed automatically with deepctl:

```bash
pip install deepctl
```

## Commands

| Command | Entry Point |
|---------|-------------|
| `deepctl plugin` | `deepctl_cmd_plugin.command:PluginCommand` |

## Dependencies

- `packaging>=21.0`
- `toml>=0.10.2`
