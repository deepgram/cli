# deepctl-cmd-update

> Part of [deepctl](https://github.com/deepgram/cli) — Official Deepgram CLI

Update command for deepctl

## Installation

Installed automatically with deepctl:

```bash
pip install deepctl
```

## Commands

| Command | Entry Point |
|---------|-------------|
| `deepctl update` | `deepctl_cmd_update.command:UpdateCommand` |

## Dependencies

- `click>=8.0.0`
- `pydantic>=2.0.0`
- `rich>=13.0.0`
- `packaging>=21.0`
- `httpx>=0.24.0`
